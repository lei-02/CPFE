# PFEM 向 CPFE 迁移设计

## 1. 目标与边界

本项目以 PFEM 论文的原始范式为准，将其迁移到具有路径依赖和内部变量的晶体塑性有限元问题：Transolver 通过纯物理损失预训练，逐载荷增量预测节点位移增量的低保真初值；独立于 Abaqus 的 CPFE Newton 求解器从该初值出发获得高精度收敛解。

首个子项目只覆盖 Oxford UMAT CASE2、FCC 12 滑移系、Kocks-Mecking 位错硬化、小变形载荷水平下的三维准静态单调拉伸，以及规则 C3D8 体素网格。网络不直接预测应力、滑移、取向或位错密度；这些量由收敛后的物理求解产生。

首版不包含周期边界、复杂非比例加载、多相材料和跨硬化方程训练。它们在基础本构、全局平衡和 warm-start 加速得到验证后加入。

## 2. PFEM 原则及 CPFE 必要扩展

保留 PFEM 的四项核心原则：

1. 以非结构点云形式编码坐标、材料信息和边界条件。
2. Transolver 输出节点位移场。
3. 训练仅依赖控制方程，不使用 CPFEM 位移、应力或状态标签。
4. 算子输出作为传统数值求解器的 warm start，最终精度由收敛准则保证。

CPFE 与论文中的超弹性不同，具有载荷路径和历史依赖，因此不能直接跳到最终载荷。对每个载荷增量重复一次“算子预测—Newton 收敛—状态提交”，并将上一步已提交的状态作为下一步输入。试算失败或全局不收敛时不得修改已提交状态。

## 3. 首个验证体系

验证按以下顺序进行：

1. 单材料点：给定变形梯度历史，比较独立 CASE2 内核与 Oxford Fortran 参考实现。
2. 单晶单元：一个 C3D8 单元，验证恒定应变、节点内力、切线、边界条件和历史提交。
3. 小型多晶：`4 x 4 x 4` 个 C3D8 单元组成单位立方体，使用固定随机种子生成 8 个 Voronoi 晶粒，为每个晶粒分配一个 FCC 取向。
4. 首版边界条件：底面约束法向位移并施加消除刚体运动所需的最小约束，顶面施加单调轴向位移；侧面无外力。该设置用于验证全场求解，不用于报告严格 RVE 等效性质。

多晶模型使用 2 x 2 x 2 高斯积分。晶粒取向和材料状态保存在积分点，不在晶界处做物理平均。

## 4. 软件组件

### 4.1 Oxford 参考后端

将原 Fortran 中 CASE2 所需例程隔离为无 Abaqus 依赖的材料点驱动器，输入为 `F_n`、`F_{n+1}`、时间增量、材料参数和已提交状态，输出为 Cauchy 应力、一致切线和试算状态。该后端是数值金标准，也可作为首版独立求解器的 CPU 本构后端。

### 4.2 可微 CASE2 后端

提供批量 PyTorch 实现，用于纯物理预训练。它复现 CASE2 的乘法分解、12 个滑移系、滑移律、Kocks-Mecking SSD 更新、CRSS、塑性变形梯度和晶格取向更新。每个更新量必须先通过 Fortran 后端的材料点历史测试，才可进入训练损失。

### 4.3 C3D8 有限元内核

负责形函数、显式空间微分、高斯积分、变形梯度、节点内力、全局残差以及材料与几何切线装配。Dirichlet 条件通过自由度消元强制施加。

### 4.4 增量 Newton 求解器

每个增量保存一份已提交状态和若干试算状态。求解器支持残差与位移增量双重收敛检查、线搜索和载荷切分。算子初值非法或效果较差时，自动退回常规增量预测，不影响最终正确性。

### 4.5 Transolver 算子

网络骨干沿用 PFEM-main 的 `Transolver_Irregular_Mesh` 与 physics attention。每个节点的输入至少包括：归一化坐标、边界类型及增量值、相邻晶粒取向描述、CASE2 材料参数、上一步积分点状态投影得到的节点特征和当前载荷时间。输出仅为三个节点位移增量分量。

积分点历史到节点的特征投影只用于生成 warm start，不参与物理状态更新。真实历史始终保存在积分点，并由材料内核更新。

### 4.6 物理训练器

网络预测经边界投影后进入 C3D8 内核和可微 CASE2 后端。首版采用离散平衡残差损失，而非为耗散晶体塑性强行构造总势能：

`L = ||f_int - f_ext||^2 / (F_scale^2 + epsilon) + w_s L_state`。

其中 `F_scale` 由本增量的规定载荷或弹性预测反力确定，避免不同载荷尺度支配训练；`L_state` 仅惩罚非物理状态，如 `det(F) <= 0`、负 SSD 和非法旋转。位移边界通过投影精确满足，不额外惩罚自由位移幅值。有限元形函数完成显式空间微分，训练中不使用 CPFEM 解标签。

## 5. 逐增量数据流

1. 读取网格、晶粒、材料、载荷和已提交状态 `S_n`。
2. 将积分点状态投影成算子输入特征。
3. Transolver 预测 `Delta u_NO`，并强制投影到满足位移边界条件的空间。
4. 以 `u_n + Delta u_NO` 作为 Newton 初值。
5. 每次 Newton 试算由节点位移计算积分点 `F_{n+1}`，调用 CASE2 后端获得应力、切线和试算状态，装配全局残差和切线。
6. 收敛后将试算状态提交为 `S_{n+1}`；失败则丢弃试算状态并切分载荷增量。
7. 保存节点位移、积分点应力/应变、12 系滑移、`F^p`、取向、SSD、CRSS、残差和耗时。

## 6. GND 扩展

Oxford 默认 `gndmodel=0`。在 SSD 和全局求解验证通过后，第二里程碑实现 `gndmodel=1`：从积分点 `F^p` 恢复节点场，利用 C3D8 形函数计算空间梯度与 `Curl(F^p)`，再按照 Oxford 的 B 矩阵和最小二乘投影得到刃型/螺型 GND。

GND 实现必须通过三类测试：恒定 `F^p` 给出零 GND、制造的线性 `F^p` 场给出解析 Curl、网格加密时 GND 场收敛。

## 7. 训练输入与泛化实验

首轮训练只生成无标签问题定义：随机晶粒取向、CASE2 参数扰动和载荷幅值。先以单样本 PFEM patch test 验证算子能够由物理损失收敛，再运行小规模多样本训练。

冻结权重后依次测试：

1. 训练分布内的未见取向和载荷。
2. 训练范围边界及范围外的 CASE2 参数。
3. 接口兼容的新硬化方程。

跨硬化方程不承诺算子初值精度。独立 Newton 求解器负责保证最终精度；实验需要判断冻结算子是否仍能减少迭代和总耗时。

## 8. 失败处理

- 材料点出现非有限数、负 SSD、`det(F)` 非正或局部迭代失败：拒绝试算并切分增量。
- Newton 残差增加：先线搜索；仍失败则切分增量。
- 算子初值使首次残差或变形合法性显著恶化：弃用该初值并记录回退事件。
- 任一失败路径不得覆盖已提交历史状态。
- 训练遇到非法样本：记录输入和失败阶段；只有明确属于采样域外的非法载荷才跳过，代码错误不得静默跳过。

## 9. 验证与成功标准

### 9.1 正确性

- 材料点：固定历史下，应力、SSD、CRSS、`F^p` 和取向与 Fortran 参考结果逐步比较。
- 单元：刚体运动零应变、恒定应变 patch test、内部力平衡和切线有限差分检查。
- 多晶：零初值和算子初值必须收敛到同一解；比较位移、应力、滑移、取向和 SSD 全场。
- GND：通过制造解与网格收敛测试后才纳入最终位错密度结果。

### 9.2 加速

在相同硬件、线程数、容差、网格和载荷增量下分别测量：算子推理、材料积分、装配、线性求解、总 Newton 次数和端到端时间。报告 `PFEM total = operator inference + warm-start CPFE`，不得只报告网络推理时间。

### 9.3 首个里程碑验收

首个里程碑在以下条件全部满足时完成：CASE2 材料点和单晶单元测试通过；8 晶粒模型可由零初值稳定收敛；能输出应力、应变、取向、12 系滑移与 SSD；Transolver 单样本 patch test 能降低物理残差；基准脚本能够公平比较零初值和 warm-start 的最终误差、迭代次数与总耗时。

## 10. 非目标

首个里程碑不追求工业规模网格、跨任意晶体结构、动态问题、损伤/断裂、多 GPU 训练或跨硬化方程的精度承诺。首要任务是建立可复现、可回滚、可验证的最小完整闭环。
